# Amnezia OpenCCK CIDR Converter — repository instructions

## Contract and architecture

- This is a released, independent IPv4 CIDR converter for the existing AmneziaVPN 5.x import workaround, not a VPN client, client patch or official format. Preserve native Windows PowerShell 5.1+ and Unix Bash/AWK implementations, CLI launchers, interactive RU/EN TUI, existing Windows C# standalone launcher, build scripts and supported platforms. No PHP/Composer, new language, runtime dependency, platform, compiler, API/CLI option or architecture without owner approval.
- Accept an OpenCCK HTTPS URL for `iplist.opencck.org` with `format=amnezia`, `data=cidr4`, and selected `site` values, or a local OpenCCK JSON file. Convert valid IPv4 CIDR from `hostname` to `ip`, assign `route-%06d.invalid` in input order, skip invalid/missing records and duplicates, preserve masks and first occurrence. No IPv6, network aggregation, VPN changes or implicit changes to output format. Keep UTF-8 without BOM for generated JSON and existing default output, options, `--machine-readable` and PowerShell `-PassThru` shapes. Keep RU/EN runtime messages synchronized.
- TUI wraps the native core; `gum` 0.17.0 is the existing bundled dependency. Windows standalone x64 uses the existing .NET Framework C# launcher and Windows PowerShell; Linux x64 and macOS arm64 use Bash/AWK. Source TUI needs `gum` on PATH; Unix URL mode uses curl or wget. Keep existing checksum-pinned gum downloads, native build/package layout, and MIT/GUM notices. No new dependency or upstream version without evidence and owner approval.
- Use English identifiers; meaningful changed comments RU then EN. Preserve Bash portability to macOS system tools, Windows PowerShell 5.1 syntax, LF source, UTF-8 BOM for non-ASCII PowerShell source, UTF-8 without BOM output. Keep shell quoting, literal paths, explicit errors and actual exit statuses. Do not treat arbitrary text or nested metadata as route records. Protect input and existing output from failed conversion; do not promise transactionality or arbitrary concurrency protection. Preserve the existing successful output contract and document actual boundaries, not hypothetical guarantees.
